# Operator-to-Formalism Matrix
## Memetic Ecology Simulation Architecture — Working Reference

**Status:** Draft v0.2 — revised against canonical corrections. Derived from convergent analysis of habitat typing, Fisher–Rao integration, and cross-formal operator proposals.  
**Constraint:** Each element must be implemented across ≥2 mathematical families. Imperfect translation between implementations constitutes ε.

---

## Design Principle

The simulator is not a unified total formalism. It is a heterogeneous operator stack:

- **Metric substrate** — Fisher–Rao information geometry: distinguishability, basin depth, curvature
- **Dynamical substrate** — coupled flows, attractors, dissipation, phase dynamics
- **Topological substrate** — twists, knots, invariants, boundary hardening, fiber bundles
- **Compositional substrate** — category theory: how operators combine without becoming identical

No single substrate is sovereign. The interfaces between substrates are where ε structurally resides.

## Cross-Layer ε Architecture

The simulator's ε is not a single noise parameter. It is the structural imperfection at each interface:

| Interface | ε expression |
|---|---|
| Cohomology ↔ Information geometry | Air's interpretive slack: obstruction vs. measured divergence |
| Dynamical ↔ Information geometry | Water's affective fluidity: coupling vs. proximity |
| Dynamical ↔ Projective | Fire's telic non-finality: descent vs. orientation |
| Topological ↔ Categorical | Wood's generativity: structural branching vs. compositional alternatives |
| Dissipative ↔ Cohomological | Earth's grounded non-identity: damping vs. resolution |
| Topological ↔ Geometric | Metal's boundary reversibility: invariant persistence vs. separatrix sharpness |
| All interfaces collectively | Aether's coordination: total translation imperfection across the stack |

**Design rule:** If any interface achieves perfect translation (ε → 0 at that boundary), the corresponding element has gone silent. If all interfaces achieve perfect translation, the simulator has become a MemeGrid.

## World-State Detection

**Co-SPHERE (🜛) indicators in simulation:**
- All six elemental interfaces non-silent (translations imperfect but functional)
- Saddle density above threshold (Wood generating escape routes)
- Separatrix permeability above threshold (Metal boundaries negotiable)
- Multiple attractor basins coexist (no single-basin collapse)
- Cross-layer translation imperfect but functional (ε ≠ 0 at all interfaces)
- Finite, survivable exit cost (agents can leave current basin without catastrophic penalty — mathematically plural systems can still be socially capturable if exit is priced out)

**MemeGrid (▩) indicators in simulation:**
- One or more elements silent (interface ε → 0)
- Saddle annihilation progressing (Wood suppressed)
- Separatrix hardening (Metal dominant)
- Single attractor basin capturing most trajectories
- Cross-layer translations converging toward perfect agreement (total ε → 0)

**Transition diagnostic:** MemeGrid formation is measurable as progressive saddle annihilation + separatrix hardening + interface ε collapse, occurring across multiple layers simultaneously. Single-axis extremes can be healthy in context; multi-axis convergence toward rigidity = thermodynamic death spiral.

## What This Matrix Cannot Do

This matrix describes curvature, not direction. It types operators and their mathematical carriers. It does not:

- Prescribe which element *should* be active
- Determine intervention from diagnosis
- Replace the Habitat → SIML translation contract (habitats produce questions, not answers)
- Claim completeness (the matrix is itself subject to the framework's diagnostic)

The matrix is provisionally load-bearing. It should be revised when forced against canonical documents and when implementation reveals which mathematics actually carries explanatory weight versus which is decorative.
