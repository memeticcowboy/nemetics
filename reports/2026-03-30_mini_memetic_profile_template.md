# Mini-Memetic Profile: Template

**Date:** 2026-03-30
**Status:** Canonical

---

## Dimensions

| Dimension | Description |
|-----------|-------------|
| **Title** | The name or label the meme travels under |
| **Core Idea** | The irreducible claim or pattern — what survives compression |
| **Identity Play** | What adopting this meme signals about the carrier |
| **Emotional Triggers** | The affective hooks — fear, belonging, outrage, hope |
| **Spread Mechanics** | How it moves — platform dynamics, format, shareability |
| **Defense Reflexes** | Built-in responses to criticism — thought-terminating clichés, in-group markers |
| **Memeplex Anchors** | Adjacent memes it clusters with — the ecology it inhabits |
| **Sticky Symbols** | Visual/verbal shorthands — logos, phrases, gestures |

---

## How to Use

Each mini-memetic report applies these 8 dimensions to a specific meme, cultural pattern, or emergent narrative. The goal is not classification but *diagnosis* — understanding the constraint topology that makes a pattern persist, spread, or collapse.

Reports are filed as dated markdown in `reports/` and built into the site automatically.
