Use this triadic model to describe root-source tension:

Desecration → Inversion → Control


- Desecration = perceived loss of meaning/order
- Inversion = distortion of values in the name of order
- Control = attempt to restore symbolic coherence through coercion

This avoids moralizing language while preserving analytical force, allowing for diagnosis and pathways to transformation.
