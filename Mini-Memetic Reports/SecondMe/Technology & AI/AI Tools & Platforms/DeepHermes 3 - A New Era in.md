# DeepHermes 3: A New Era in AI Reasoning

Created at 2025/02/17 8:00 PM

## Summary

Nous Research's DeepHermes 3 is an AI model that integrates deep reasoning and traditional LLM responses, allowing users to toggle between detailed reasoning and faster responses. It is based on Meta’s Llama series, with 8 billion parameters, and excels in complex problem-solving and multi-turn conversations.

## Overarching Themes

- **Advanced Reasoning Capabilities**: Enhanced performance in mathematics, logic, and complex reasoning tasks.

**🤖 DeepHermes 3: Revolutionizing AI Reasoning and User Interaction**

- **Dual-Mode Operation**: DeepHermes 3 allows users to switch between intuitive and deep reasoning modes, enhancing flexibility in responses. This feature enables users to choose between quick, straightforward answers or more elaborate, thought-out responses, catering to different needs and contexts.

- **Advanced Reasoning Capabilities**: The model excels in complex problem-solving, particularly in mathematics and logic. While it scores 67% on MATH benchmarks, it is designed to be a generalist model, offering broader conversational skills compared to specialized models like DeepSeek.

- **User Control and Customization**: Users can guide the model's behavior through system prompts, allowing for tailored interactions. This customization empowers users to dictate the depth of reasoning, enhancing the overall user experience.

**📊 Performance Insights and Community Feedback**
- **Benchmarking Results**: Early tests indicate that while DeepHermes 3 may not outperform specialized models in pure math tasks, it offers a more versatile approach to reasoning and conversation, making it suitable for a wider range of applications.

- **Multi-Turn Conversations**: Feedback suggests that while the reasoning mode activates correctly initially, it may struggle to maintain this mode in extended dialogues. Users recommend enforcing structured thinking tags to improve consistency.

- **Function Calling Integration**: The model supports tool use, but the integration of reasoning mode with function calling is inconsistent. Ongoing user feedback is crucial for refining this feature and enhancing overall performance.

**🔧 Deployment and Hardware Performance**
- **Accessibility and Compatibility**: DeepHermes 3 is available for testing on Hugging Face, with optimized versions for low-power hardware. It runs efficiently on consumer-grade devices, demonstrating its practicality for everyday use.

- **Processing Speed**: Users have reported impressive processing speeds, such as 28.98 tokens per second on a MacBook Pro M4 Max, showcasing the model's capability to handle tasks swiftly.

- **Licensing and Redistribution**: While the model is freely available, it comes with specific conditions regarding redistribution and commercial use, ensuring compliance with Meta’s licensing policies.

**📚 Data and Training Approach**
- **Diverse Dataset Composition**: DeepHermes 3 is built on a meticulously curated dataset of approximately 390 million tokens, covering various domains such as general instructions, mathematics, and creative writing, which supports its unique reasoning capabilities.

- **Training Methodology**: The model was trained on a mix of non-CoT and CoT outputs, enhancing its ability to toggle between intuitive and structured reasoning effectively.

- **Focus on User Steerability**: The design emphasizes user control, allowing for a more personalized interaction with the AI, which is a key differentiator from other models.
