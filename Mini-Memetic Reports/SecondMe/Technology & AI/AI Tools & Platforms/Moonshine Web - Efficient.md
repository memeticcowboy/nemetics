# Moonshine Web: Efficient Speech Recognition for All Devices

Created at 2025/01/13 2:46 PM

## Summary

Moonshine is a speech recognition model optimized for live transcription and voice commands, developed by Useful Sensors. It uses an encoder-decoder transformer architecture with Rotary Position Embeddings, making it more efficient and suitable for real-time applications on resource-constrained hardware. Moonshine reduces compute requirements compared to OpenAI's Whisper while maintaining accuracy.
