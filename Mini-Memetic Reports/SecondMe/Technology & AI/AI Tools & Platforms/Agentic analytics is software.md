Agentic analytics is software used for the process of data analysis that applies AI agents across different parts of the data-to-insight workflow, orchestrating tasks semi-autonomously or autonomously toward stated goals that support, augment or automate insights. Agentic analytics’ must-have capabilities are data source connectivity, data preparation, agent workflow orchestration, automated insights and natural language query. Optional capabilities include data storytelling, a metrics assistant, function calling, agent memory, embedded analytics and platform administration.
