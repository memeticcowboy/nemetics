**🌐 Launch of Diffbot's Factually Grounded Large Language Model (LLM)**

- **Accuracy and Transparency**: The Diffbot LLM prioritizes factual correctness by ensuring that all AI responses are traceable to original sources. This is achieved through rigorous citation grounding, which matches every factual statement with the specific passage that supports it, enhancing user trust and reliability.

- **Knowledge Graph Integration**: By leveraging Diffbot’s extensive Knowledge Graph, which contains over 10 billion entities and 1 trillion structured facts, the LLM retrieves real-time information. This integration allows the model to provide precise and authoritative responses, surpassing other LLMs in factual reliability and domain coverage.

- **Open-Source and Privacy**: The model is designed with a privacy-first approach, allowing users to self-host and maintain control over their data. This open-source implementation empowers developers and researchers to integrate the model into their systems while ensuring data security and confidentiality.

**📊 Performance Metrics and Benchmarks**
- **Unmatched Factual Performance**: The Diffbot LLM has achieved an MMLU-Pro score of 70.36 and a FreshQA score of 81, outperforming other open-source models with less than 100 billion parameters. This performance is attributed to the model's unique architecture and its reliance on the Knowledge Graph for factual accuracy.

- **Graph Retrieval Augmented Generation (GraphRAG)**: This innovative system allows the LLM to dynamically query the Knowledge Graph and an independent web search index, providing real-time access to verifiable sources. This contrasts with traditional LLMs that rely solely on internal training data.

- **Real Citation Grounding**: Unlike other models that may provide misleading citations, Diffbot’s LLM ensures that every statement is backed by a direct citation to the original source, enhancing the transparency of the information provided.

**🔍 Advanced Multimodal and Tool Capabilities**
- **Image Entailment**: The LLM can interpret and explain images, facilitating complex visual reasoning. This capability allows users to engage with the model in a more interactive manner, extending beyond text-based queries.

- **Code Interpretation**: The model can execute JavaScript code internally, providing definitive answers to programming-related queries. This feature is particularly beneficial for developers and data scientists who require accurate solutions.

- **Complex Workflow Integration**: Diffbot’s LLM excels in aggregating data on-demand and generating insights from user-selected datasets, making it a powerful tool for various applications.

**💻 Public Demo and Accessibility**
- **Diffychat Platform**: Users can explore the capabilities of the Diffbot LLM through the public demo available at https://diffy.chat. This platform allows developers, researchers, and organizations to test and integrate the model into their projects.

- **Open-Source Repositories**: The model is fully open-weight and compatible with OpenAI’s function-calling API server, enabling users to self-host and customize their implementations while maintaining full control over their configurations.

- **Community Engagement**: Diffbot encourages contributions from developers and researchers, fostering a collaborative environment for enhancing the model and its applications.

**🔒 Data Security and Control**
- **Privacy-First Design**: The LLM is engineered to prioritize user data security, allowing sensitive information to remain within a secure, on-premise environment. This design is crucial as data confidentiality becomes increasingly important in AI applications.

- **Self-Hosting Options**: Users have the flexibility to self-host the model, ensuring that their data is not exposed to external servers. This feature is particularly appealing to enterprises concerned about data privacy.

- **User Empowerment**: By providing an open-source model, Diffbot empowers users to take control of their data and customize the model according to their specific needs and requirements.
