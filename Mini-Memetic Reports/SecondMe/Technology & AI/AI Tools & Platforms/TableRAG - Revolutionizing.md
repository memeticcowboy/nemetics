# TableRAG: Revolutionizing Table Understanding with RAG

Created at 2024/10/12 7:04 PM

TableRAG introduces a Retrieval-Augmented Generation framework to improve large-scale table understanding by enhancing retrieval through query expansion, schema, and cell retrieval. This reduces prompt length and information loss, achieving state-of-the-art performance on new million-token benchmarks.
