# Neuroscape Cognitive Enhancement Technologies

Created at 2024/07/13 8:42 AM

Neuroscape’s interventions and diagnostics focus on developing and validating software for cognitive enhancement and assessment. Key technologies include:

	1.	NEXUS: A remote platform for clinical trials and assessments.
	2.	ACE: Mobile cognitive control assessment tool.
	3.	Glass Brain: Real-time brain visualization technology.
	4.	RCM: Cognitive characterization app for memory and task planning.
	5.	Rhythmicity: Game assessing sensorimotor synchronization.
	6.	Beep Seeker: Game to improve distraction filtering.
	7.	Big Fish Competition: Game assessing attention skills.
	8.	Body Brain Trainer: Integrated cognitive and physical training.

For more details, visit Neuroscape.

## Insight
Neuroscape focuses on developing and validating software for cognitive enhancement and assessment. Their technologies, such as NEXUS, ACE, and Glass Brain, are designed to improve cognitive functions through engaging, closed-loop video games and assessment tools. These tools have shown measurable impacts on cognitive abilities, making them valuable for researchers, clinicians, and the general public. If you're looking to enhance cognitive skills or conduct cognitive research, Neuroscape's innovative tools could be highly beneficial. Let's dive into the details of each technology.

**🧠 NEXUS Platform**
- **Remote Clinical Trials**: NEXUS facilitates large-scale clinical trials and assessments remotely, allowing participants to engage in research from their devices.
- **Comprehensive Study Management**: The platform handles recruitment, authentication, consenting, characterization, randomization, treatment, outcomes, and follow-up digitally.
- **Data Security**: NEXUS uses AWS for data storage, meets HIPAA compliance, and requires multi-factor authentication for access to protected health information.

**📱 ACE (Adaptive Cognitive Evaluation)**
- **Mobile Cognitive Assessment**: ACE evaluates cognitive control through interactive tasks on mobile devices, assessing attention, working memory, and goal management.
- **Adaptive Algorithms**: Tasks are completed in about 5 minutes, with algorithms ensuring fair comparisons across diverse populations.
- **Global Availability**: ACE aims to create a large normative database accessible to researchers, clinicians, educators, and the public worldwide.

**🧠 Glass Brain**
- **Real-Time Brain Visualization**: Glass Brain uses MRI and EEG data to display real-time brain activity and connectivity in a 3D model.
- **Unity 3D and NVIDIA GPU**: The technology is built on the Unity 3D game engine and powered by NVIDIA’s GPU computing for rapid visualization.
- **Research and Artistic Use**: Besides research, Glass Brain has been featured in art projects, museums, and documentaries, winning the 2015 Popular Science Vizzie Award.

**📊 RCM (Characterization Module)**
- **Memory and Task Planning Assessment**: RCM is a tablet-based app that assesses memory and task planning using self-directed cognitive tasks.
- **Speech Recognition Technology**: The app employs online speech recognition for ease of use, especially beneficial for older adults and patient populations.
- **Standardized Tests**: RCM replicates standardized neuropsychological tests like CVLT-II and Digit Span, completed in about 30 minutes without an experimenter.

**🎮 Rhythmicity**
- **Sensorimotor Synchronization**: Rhythmicity assesses synchronization abilities with auditory, visual, and tactile stimuli through a tablet-based game.
- **High Test-Retest Reliability**: The game demonstrates high reliability and has been used by individuals aged 8 to 80.
- **Multiple Synchronization Types**: Users can choose from on-beat, off-beat, and continuation synchronization types.

**🎯 Beep Seeker**
- **Distraction Filtering**: Beep Seeker is a mobile game designed to improve the ability to filter distractions, crucial for high-level performance.
- **Adaptive Difficulty**: The game adjusts its difficulty based on the participant’s performance, making it suitable for all ages and cognitive abilities.
- **Research and Practical Use**: It is used in both basic research studies and practical applications for individuals with ADHD and older adults.

**🐟 Big Fish Competition**
- **Attention Skills Assessment**: This game assesses attention skills, including impulsivity and sustained attention, in a gamified environment.
- **Broad Applicability**: Designed for individuals of all ages and cognitive abilities, it helps understand underlying components of attention.
- **Engaging Gameplay**: The game’s engaging format ensures participants remain motivated and focused during assessments.

**🏋️‍♂️ Body Brain Trainer (BBT)**
- **Integrated Cognitive and Physical Training**: BBT combines cognitive and physical exercises in a motion capture video game to enhance cognitive abilities.
- **Adaptive Algorithms**: The game uses adaptive algorithms to target ideal heart rates and cognitive challenges, optimizing performance.
- **Engaging Storyline**: An action-adventure storyline with Mayan warriors and immersive soundscapes keeps participants engaged.
