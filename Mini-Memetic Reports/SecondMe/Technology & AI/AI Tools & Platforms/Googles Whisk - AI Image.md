# Google's Whisk: AI Image Generation Revolution

Created at 2024/12/31 10:37 AM

## Summary
Google's Whisk is an AI tool that allows users to generate images by uploading and combining multiple images as prompts, rather than using text. It uses Google's Imagen 3 model for image generation and is designed for rapid visual exploration and creative experimentation.
