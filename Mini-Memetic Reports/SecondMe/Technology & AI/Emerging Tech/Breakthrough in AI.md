## 3. **Fundamental Concepts**

- **Diffusion Models**: Generate output through iterative refinement from noise rather than sequential token generation.
- **Autoregressive Models**: Traditional sequential token generation, slow and computationally expensive.
- **Test-Time Compute**: Computational resources spent during inference to improve model reasoning capabilities.
- **Mercury Coder**: The first production-grade diffusion-based LLM developed by Inception Labs, optimized for code generation.
- **Iterative Refinement**: Gradually improving initial coarse outputs into refined, accurate results.
- **Agentic Workflows**: AI agents working autonomously, whose performance relies heavily on inference speed.
- **Controllable Generation**: Ability of diffusion models to edit and infill text, aligning closely with user objectives.

***

## 4. **Essential Information**

- Diffusion-based LLMs claim to be **10x faster and 10x cheaper** than traditional autoregressive LLMs.
- Mercury Coder demonstrates **1,000+ tokens per second** inference speed on standard Nvidia H100 hardware.
- Traditional autoregressive models (e.g., GPT-4, Claude) generate tokens sequentially, severely limiting speed.
- Mercury Coder rapidly generates code snippets, significantly outperforming GPT and Claude in practical demonstrations.
- Diffusion-based models enable parallel refinement of text, improving not just speed but also output accuracy.
