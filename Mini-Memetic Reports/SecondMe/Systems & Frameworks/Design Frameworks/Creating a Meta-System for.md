**3️⃣ Principles and Prompts for Processing and Consolidation**


Here are principles and meta-prompts you can use to process new material and sort it into your meta-system:




**🧭 PRINCIPLES**


✅ Compression before Expansion

- Can this idea be reduced to a simpler transferable model?
- Which of the 5 Domains is its home?


✅ Recursive Reflection

- How does this model itself model the act of modeling?


✅ Operationalization

- What are 2–3 ways this framework can be used today?


✅ Ethical Contextualization

- What unintended consequences or path dependencies might it embed?


✅ Relational Linking

- Which existing frameworks does it strengthen, contradict, or evolve?





**🧰 META-PROMPTS**


When analyzing new concepts, use these standardized reflection prompts:



1. Domain Mapping Prompt

Which of the 5 Integrative Domains does this primarily belong to? Could it live in more than one?

2. Compression Prompt

What is the core 1–2 sentence definition of this idea, stripped of jargon?

3. Use Case Prompt

List 3 specific scenarios in which this idea becomes actionable.

4. Contradiction Prompt

Which of my other frameworks does this idea challenge or complicate?

5. Future Resonance Prompt

If this idea spreads widely, what would change in culture, systems, or ethics?
