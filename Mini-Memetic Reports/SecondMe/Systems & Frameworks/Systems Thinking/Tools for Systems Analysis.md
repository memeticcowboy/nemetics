# Tools for Systems Analysis

Created at 2025/06/10 9:42 PM

## Causal Loop Diagrams
- Visualize feedback loops
- Understand interactions between variables over time

## System Dynamics Modeling
- Use software like Vensim or Stella
- Simulate complex systems and predict changes

## SWOT Analysis
- Identify strengths, weaknesses, opportunities, and threats

## Fishbone Diagram (Ishikawa)
- Conduct root cause analysis
- Break down potential causes into categories

## Soft Systems Methodology (SSM)
- Focus on understanding different perspectives
- Suitable for messy, human-centric problems

## Network Analysis Tools
- Use tools like Gephi or NodeXL
- Analyze and visualize complex networks

## Scenario Planning
- Create narratives about different future scenarios
- Test system responses to various changes

## Monte Carlo Simulation
- Model probability of different outcomes
- Useful for processes influenced by random variables
